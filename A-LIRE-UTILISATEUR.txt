ZAAPS DOFUS 3 — 1.1.5
Windows 10/11 x64

1. Fermer toute ancienne instance de Zaaps Dofus 3.
2. Extraire entièrement l'archive.
3. Ouvrir Ganymède sur le guide souhaité.
4. Lancer « Zaaps Dofus 3.exe ».

Ctrl+J : copier le Zaap recommandé.
Ctrl+K : copier la destination /travel.
Ctrl+L : copier le trajet complet disponible.
Ctrl+Shift+A : suspendre / reprendre Auto.
Ctrl+Shift+Z : afficher / masquer la fenêtre.

La vue compacte affiche l'étape, le Zaap et la destination.
« Afficher les 45 Zaaps » déplie le gestionnaire et sa recherche.
Le mode compact est mémorisé au prochain lancement.

« Accrocher à Ganymède » réunit les fenêtres. Choisir en haut, en bas,
à gauche ou à droite : Zaaps se place de ce côté de Ganymède.
Déplacer l'une entraîne l'autre ; redimensionner conserve l'alignement.
Les bords visibles s'alignent sans espace. En haut et en bas, Zaaps suit
la largeur de Ganymède et garde sa hauteur compacte. Sur les côtés,
les fenêtres s'alignent en haut. Ganymède conserve sa propre taille.
L'option et le côté sont mémorisés.
Décocher pour séparer les fenêtres. Option désactivée par défaut.
L'accrochage est en pause si une fenêtre est masquée, réduite ou maximisée.
Si l'écran manque de place, choisir un autre côté ou réduire les fenêtres.
La vue accrochée mesure environ 225 pixels de haut. « Afficher Zaaps »
ouvre le gestionnaire à part. L'engrenage ouvre les réglages, avec le
choix du côté, la désactivation de l'accrochage et le diagnostic.

Le bouton − réduit le logiciel près de l'horloge. Les raccourcis et la
copie automatique restent actifs. Cliquez sur l'icône pour le retrouver.
Clic droit : afficher, suspendre Auto, recopier le trajet ou quitter.
Le bouton × ferme complètement l'application.

Avec un Zaap et une destination : double /zaap puis /travel.
Avec seulement un Zaapi ou sans Zaap : /travel seul si exploitable.
Sans destination exploitable : aucune copie.

Si la prochaine destination annoncée est Enutrosor, Srambad, Xélorium,
Ecaflipus ou Osavora : trajet vers la Tour des Voyageurs Dimensionnels
en [-22,-24], via le Zaap Routes Rocailleuses en [-20,-20].
Ctrl+J copie le Zaap d'accès, Ctrl+K le voyage vers la Tour,
Ctrl+L le trajet complet. Les coordonnées internes de la dimension
ne sont pas utilisées pour ce voyage.

Auto copie à la prochaine nouvelle étape reconnue. L'étape présente
à l'activation sert de référence et n'est pas copiée automatiquement.
Les raccourcis se modifient dans les réglages.
« Toujours au premier plan » garde Zaaps au-dessus des autres applications.
Cochez ou décochez cette option, puis Enregistrer ; le choix est mémorisé.

Réglages : confirmation visuelle, son léger ou silence ; avertissement
si la commande copiée est remplacée ; lancement avec Windows facultatif
et désactivé par défaut. Si vous activez ce lancement, placez d'abord
le dossier à son emplacement définitif. Après un déplacement du dossier,
enregistrez à nouveau les réglages pour actualiser l'emplacement.

La vérification de version consulte GitHub et signale les nouvelles
Releases stables. Aucun fichier n'est téléchargé ou installé automatiquement.
Elle peut être désactivée ou déclenchée manuellement dans les réglages.

Diagnostic : aperçu modifiable avant copie ; rien n'est envoyé
automatiquement. Le texte complet du guide et le contenu remplacé
du presse-papiers ne sont pas inclus.

Le logiciel copie uniquement dans le presse-papiers. Coller manuellement
dans Dofus. Aucune installation de Rust nécessaire pour utiliser l'EXE.

Préférences : %APPDATA%\Zaaps Dofus 3\raccourcis.ini
